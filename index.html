Turn scholarly books into trusted section corpora.

BOOKCORPUSBUILDER is a PySide6 desktop workbench for converting PDF books into reviewed, page-aligned, provenance-tracked text, JSONL, and manifest outputs. Automation assists; the operator remains the approval authority.

A governed document-processing system

The application solves the difficult part of corpus building: maintaining the distinction between source structure, printed pagination, physical PDF position, operator approval, and extraction authority.

Human-reviewable outlines

Paste, import, detect, or manually construct a candidate outline, then review and approve it before use.

Verified page alignment

Map printed page labels to physical PDF pages using operator-checked anchors and explicit exceptions.

Controlled extraction

Extraction remains blocked until the outline and mapping have passed deterministic preflight checks.

Auditable deliverables

Create run-scoped UTF-8 text files, JSONL records, manifests, hashes, and immutable execution history.

Local corpus search

Search extracted sections locally and trace results back to the source PDF and generated outputs.

Optional local assistance

Local Ollama may propose schema-constrained candidates, but cannot approve, map, or extract.

Engineering philosophy

The v1.0 baseline was produced through bounded refinement, regression preservation, real-GUI verification, governance, audit, and release review.

01Inspect before modifying.
Understand the existing mechanism and its contract before intervention.
02Reuse before inventing.
Prefer established services, models, and interaction patterns.
03Preserve behaviour.
Changes are bounded unless a behavioural change is explicitly authorized.
04Verify the real interface.
GUI claims require real-GUI evidence, not code inspection alone.
05Regress after every change.
Tests preserve accepted behaviour and prevent repaired defects from returning.
06Governance over convenience.
Frozen architecture and approval boundaries are engineering controls.
07Synchronize documentation.
Manuals, governance, issues, and release records are part of the product.
08Audit before release.
Product quality and release-process quality are assessed separately.

Install and launch

Python 3.10 or newer is required. Install the GUI extra in a fresh virtual environment.

git clone https://github.com/ambijat/BOOKCORPUS_BUILDER.git
cd BOOKCORPUS_BUILDER

python3 -m venv .venv
.venv/bin/pip install -e '.[gui]'
.venv/bin/bookcorpus-gui

Optional analysis, text-to-speech, development, and local Ollama integrations are documented in README.md.
